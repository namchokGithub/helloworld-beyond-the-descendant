# HelloWorld: Beyond the Descendant

_Rest the weary heart._

A personal Minecraft fantasy adventure modpack focused on exploration, discovery, and having fun with friends.

**Minecraft:** 26.1.2
**Mod Loader:** NeoForge
**Status:** Beta

[View on CurseForge](https://www.curseforge.com/minecraft/modpacks/helloworld-beyond-the-descendant)

---

## The Story

Once, I wandered through the unforgiving world of **Cisco's Fantasy Medieval RPG [Ultimate]**.

It was a cruel world filled with danger and countless challenges. But somehow, I survived.

After a long journey, I finally closed my eyes and fell into a deep slumber.

When I awoke, everything had changed.

**The world had moved on to 26.1.2.**

The lands were unfamiliar, old adventures had become distant memories, and **The Ascendant was nowhere to be found.**

Now, only one question remains:

_What should I do with this second life?_

Perhaps it's time to stop fighting for survival and simply enjoy the world.

Explore forgotten places, discover hidden treasures, build a home, and make new memories.

**The old journey has ended. A new one begins.**

## Installation

### Recommended: CurseForge App

1. Install the [CurseForge App](https://www.curseforge.com/download/app).
2. Select **Minecraft**.
3. Search for **HelloWorld: Beyond the Descendant**.
4. Install the latest available version.
5. Launch Minecraft and enjoy your adventure.

### For Developers

This repository contains source files and configurations used to develop the modpack.

It is **not a complete standalone Minecraft installation**.

To work on the modpack:

1. Install the latest version through CurseForge.
2. Create a separate development profile.
3. Clone this repository.
4. Copy the relevant configuration files into your development profile.
5. Test your changes before exporting a new release.

Some mods and third-party assets are excluded from this repository due to licensing and distribution restrictions.
